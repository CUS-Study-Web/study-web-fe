# Folder Structure

This project is a Vite + React + TypeScript frontend located in `study-web-fe`.

`public/` - Static files that are served directly by Vite.

`src/` - Main application source code.

`src/assets/` - Local images, icons, and other imported assets.

`src/components/` - Reusable UI components.

`src/contexts/` - Shared React context providers and state.

`src/hooks/` - Custom React hooks.

`src/pages/` - Page-level views.

`src/types/` - Contains models or entities definition.

`src/routes/` - Route definitions and navigation setup.

`src/services/` - API calls and data access logic.

`src/styles/` - Shared styles and style-related files.

`src/utils/` - Helper functions and utility code.

`src/App.tsx`, `src/main.tsx`, and `src/index.css` - Application entry points and global styling.
